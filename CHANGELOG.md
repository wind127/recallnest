# Changelog

## 0.1.0 — 2026-10-14

Initial local, single-user release.

- Import ChatGPT JSON/ZIP, Codex JSONL, normalized JSON and Markdown, preserving raw records, branches and source versions.
- Consolidate conversations into cited knowledge, review cards and personal-memory candidates through an optional OpenAI-compatible provider.
- Capture an explicitly selected Codex directory and accept submissions through REST and MCP.
- Search and browse knowledge, project records and sources; use optional embeddings for hybrid retrieval.
- Confirm, correct, reject, expire and supersede personal memories, preserving history and showing the background used in chat.
- Review editable cards with a transparent interval schedule and saved feedback.
- Export complete JSON archives and readable Markdown; run from source or with Docker Compose.

ChatGPT web auto-capture, referenced-media interpretation, model training, full archive restoration and public multi-user hosting are outside this release.
