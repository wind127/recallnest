# 记忆与复习

知巢把原始会话、知识条目和个人记忆分别保存。原文是可回查的来源；知识条目帮助理解和复习；个人记忆描述你确认过的偏好、背景、目标、状态与约束。

## 什么可以成为个人记忆

例如，你说“我希望今年完成一个开源项目”，可以产生带原文引用的目标候选。你问“怎样学习 Java”，不等于你已经会 Java。助手对你的推断也不等于你陈述过的事实。

自动整理产生的记忆默认是候选。你可以修改内容、查看来源，再确认或拒绝。只有当前生效的已确认记忆才可以作为后续回答的个人背景。未配置模型时，你仍可手动记录和管理记忆。

| 状态 | 含义 | 作为当前背景 |
| --- | --- | --- |
| 候选 | 等待你核对 | 否 |
| 已确认 | 你已认可的内容 | 在生效期内可用 |
| 拒绝 | 内容不准确或不适合记录 | 否 |
| 失效 | 已不适用于当前情况 | 否 |
| 已替代 | 被后来的记忆取代 | 否 |

## 状态变化与历史

当“正在找工作”变成“已入职”，新增一条状态记忆，并指定它替代原记忆。替代项保持候选时，旧记忆仍有效；确认替代项后，旧记忆成为已替代，历史与证据继续保留。

替代项应当具有相同类别和主题。未来生效的替代项先保持候选，等到生效时再确认。拒绝或设为失效不会自动恢复已经被替代的旧记忆。

## 来源版本

引用包含会话、消息、消息版本和原文片段。来源消息修改后，旧版本仍然可以查阅，相关引用标记为过时。确认记忆时请核对引用；确认本身不是对未来原文变更的永久担保。

有引用的记忆需要至少一条有效的当前证据才进入回答背景。相同记忆后来获得新证据时，可以继续使用；旧证据留在详情和归档中，回答上下文只带当前证据。没有引用的手写确认记忆仍可使用。

手写条目允许没有引用。系统不会为手写内容编造来源。完整 JSON 导出保存会话分支、消息版本、引用、记忆历史和复习记录；Markdown 导出适合阅读。

## 复习方法

卡片先显示问题，点击揭示答案后再反馈。按项目和到期日期筛选可以组成复习集合；卡片可以编辑、暂停，或指定下次到期时间。

| 反馈 | 下次复习间隔 |
| --- | --- |
| 忘记 | 10 分钟 |
| 困难 | 至少 1 天，或前一次间隔的 1.2 倍 |
| 记住 | 至少 3 天，或前一次间隔的 2 倍 |
| 轻松 | 至少 7 天，或前一次间隔的 3 倍 |

间隔从反馈时刻计算，每次反馈都保存历史。这是一套透明的简单间隔规则，没有实现 FSRS。暂停的卡片不会进入到期队列，也不能评分。

## “越来越了解”的含义

知巢通过积累和检索你确认过的记忆，为回答提供相关背景，并显示使用过的上下文。它不会训练或修改模型权重。你可以随时核对、纠正、拒绝或让旧背景失效。
