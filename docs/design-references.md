# 设计参考

RecallNest 独立实现本地归档、证据引用、复习与个人记忆流程，采用 MIT 许可证。以下项目帮助确定产品方向；没有把它们的源码、界面资源或品牌资产复制进本仓库。

| 项目 | 参考方向 |
| --- | --- |
| [Mem0](https://github.com/mem0ai/mem0) | 从会话提取记忆，再将相关记忆用于回答 |
| [Khoj](https://github.com/khoj-ai/khoj) | 个人知识库与检索入口 |
| [Basic Memory](https://github.com/basicmachines-co/basic-memory) | 可阅读知识、观察记录与关联 |
| [Open WebUI](https://github.com/open-webui/open-webui) | 会话管理与模型配置的交互思路 |

项目热度查询快照和路线比较保存在[首版设计提案](superpowers/specs/2026-10-14-recallnest-design.md)。Star 数会变化，不代表所有功能或质量都适合本项目。

具体资料：[Mem0 memory operations](https://docs.mem0.ai/core-concepts/memory-operations/add)、[Basic Memory knowledge format](https://docs.basicmemory.com/concepts/knowledge-format/)，以及各项目官方 README。

后续贡献若引入第三方代码，需检查对应文件的许可证、版本与署名要求，不能把“参考产品思路”当作复制代码的许可。
